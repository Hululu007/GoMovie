# GoMovie 设计语言 v2：海报沉浸 + 封面取色 + 统一控件

三条主线，一次定下来，后面所有页面照这个做。

---

## 1. 封面取色（所有强调色都从这里来）

### 取色

- 拿 `vod_pic` 走 `package:image` 缩到 **32×57** 取直方图（不要 Worker，不要大图）。
- 过滤掉近黑 / 近白 / 低饱和像素，剩下的按面积加权取主色。
- **钳制**（不是挑好看）：HSV 的 `s` 夹到 `0.45–0.80`，`l` 抬到与该页底色对比 **≥ 4.5:1**。
- 文字色不手挑：`onAccent = max(contrast(白, accent), contrast(#0b1120, accent))`，数学上恒 ≥ 4.58:1。

### 派生 token（一次算好，别用 color-mix）

| token | 值 | 用在哪 |
|---|---|---|
| `--accent` | 钳制后的主色 | 主按钮底、选中态边框、进度条、评分文字 |
| `--on-accent` | 黑或白 | 主按钮文字 |
| `--accent-deep` | 同色相 l≈0.12 | 主按钮渐变深端、沉浸层压暗 |
| `--accent-tag` | 主色 22% | 标签底、选集当前集底 |
| `--accent-a08 / a12 / a18 / a35` | 主色 8/12/18/35% | 分档衬色（见 §3） |

### 缓存与冷启动

- 按 `dramaId` 缓存 scheme；启动先读上次成功那套，避免首页未出封面时闪回默认色。
- 换剧才换色；**同一部剧换集不换色**（缓存键用封面 URL，不用集数）。

## 2. 海报沉浸（详情 / 播放 / 首页 Hero）

三层叠法，只在有留白时挂：

```
层1  封面缩到 64 宽 → background-size: cover 铺满（放大即柔焦）
层2  --accent-a35 乘色（overlay）
层3  底部 40% 渐隐到页面底色 #0b1120（控件有底可压）
```

- 滤镜：`blur(12px) brightness(.5) saturate(1.7)`；**不要对原图做 blur(40px)**（弱机很贵）。
- 容器 `inset: -12%` 撑出界，避免呼吸动画露边。
- 动效：`scale 1.08 → 1.12`，18–24s 交替，只动 transform。
- 换剧时两层交叉淡入 0.5s，不要直接换 `background-image`（会闪底）。
- **空数据回退**：没有封面时走品牌径向渐变，并且这条路径要单独验一次（背景亮度不同，半透明控件会露馅）。

## 3. 衬色分档（同一套色，不同浓度）

| 页面 | 衬色 |
|---|---|
| 播放 / 详情（沉浸） | 35% |
| 我的 | 18% |
| 首页 / 分类 / 列表 | 12% |
| 搜索（只染一个角） | 8% |
| 设置 / 条款（文字密集） | **0**，不跟色，实色分组 |

## 4. 统一控件规范（全站唯一一套）

| 控件 | 高度 | 圆角 | 字号 | 说明 |
|---|---|---|---|---|
| 胶囊 chip（分类/筛选） | 36 | 999 | 13 | 选中＝`--accent-tag` 底 + `--accent` 描边 |
| 副按钮 / 图标钮 | 44 | 12 | 14 | 底 `rgba(255,255,255,.10)` + 描边 8% |
| 主按钮 CTA | 52 | 13 | 15/700 | `--accent → --accent-deep` 渐变，文字 `--on-accent` |
| 列表行 | 56 | — | 15 | 右侧值 12 号 55% 白 |
| 选集格 | 48 | 11 | 13.5 | 当前集 `--accent-a35` + `--accent` 描边 |
| 卡片 | — | 12 | 标题 13/600 | 图下文字版；沉浸版用底部渐变叠字 |
| 分组容器 | — | 16 | — | 底 `#121826`，**不加描边**（描边是廉价感来源） |

- 字号层级只用 6 档：`11 / 12 / 13 / 15 / 17 / 22`，页面大标题 22，不再出现 32。
- 描边统一 `1px rgba(255,255,255,.08)`；阴影只保留两档：卡片 `0 12px 26px rgba(0,0,0,.35)`，浮层 `0 18px 40px rgba(0,0,0,.55)`。
- 动效时长只用两个值：**180ms**（状态切换）/ **220ms**（面板进出），曲线 `cubic-bezier(.2,.8,.2,1)`。
- 状态四件套：normal / pressed（缩放 0.97 + 亮度 −8%）/ selected（accent 描边 + 22% 底）/ disabled（40% 白）。

## 5. 落地顺序（Dart）

1. `lib/theme/tokens.dart`：颜色/圆角/间距/字号/动效常量，先只定义不接线。
2. `lib/theme/accent.dart`：取色 + 钳制 + 派生 + `onAccent()`；单测覆盖对比度 ≥4.5。
3. `AccentScope`（InheritedWidget）+ `ThemeExtension`：挂在 `MaterialApp` 外层。
4. `StageBackdrop`：三层叠法 + 呼吸动画 + 交叉淡入 + 空数据回退。
5. 分批替换写死颜色：`grep -nE '#[0-9a-fA-F]{6}|Colors\.(red|orange|blue|white)' lib/ui | wc -l` 归零。
6. 详情页 → 播放页 → 首页 Hero 依次接入（每步一个可回滚 commit）。

## 6. 验收（不靠肉眼）

- 对比度自测：正文/标题/胶囊各抽一组，≥4.5 才算过。
- 同一页换两部剧截图，**色相必须不同**（暖橙 vs 青绿）。
- 空列表 / 无封面两条回退路径各截一张。
- 设置页截图确认**不带任何衬色**。
- 真机（小米9）截图，先核 APK md5 再看 UI。
